# Rasel Mia Portfolio

A single-page portfolio site for an AI Content & Automation Specialist / Digital Marketing expert.

## Tech

- Plain HTML5, no build step
- Tailwind CSS via CDN (with a custom config for brand colors and fonts)
- Vanilla JavaScript for interactivity (light/dark theme toggle, animated canvas background)
- Google Fonts (Plus Jakarta Sans, JetBrains Mono)

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server, e.g.:

```bash
npx serve .
```

## Deployment

This is a static site with a single `index.html` entry point, ready to deploy as-is on Netlify.
